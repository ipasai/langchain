Core Advantages

系統核心優勢 (Core Advantages)

打造靈活、隱私與高效並重的個人智慧工作站

多模型彈性切換

支援本地端 Ollama 等多種 AI 供應商與模型（如 qwen2.5:1.5b），兼顧隱私防護與計算效能。

專屬角色設定 (Persona)

可依需求隨時切換 AI 角色（如：資料庫專家），提供更精準、具備領域專業知識的互動回應。

輕量化在地儲存

整合本機 SQLite 資料庫，資料完全由個人自主掌控，離線也能穩定運作與快速讀取。

Technical Stack

核心工具與技術棧 (Technical Stack)

結合頂級開源框架，建構穩固可靠的系統架構

🖥️ 前端互動介面：Streamlit

負責整個應用的 Web UI 視覺化呈現與響應式元件互動（包含導覽列、側邊欄、對話框與動態數據表格）。

🤖 AI 應用編排框架：LangChain

系統的核心大腦。負責串接 AI 模型、管理 Prompt 提示詞、動態切換 Persona 角色設定及建立對話記憶。

🧠 本地 LLM 模型：Ollama (qwen2.5:1.5b)

100% 在地化運行 AI 任務（對話、SQL 生成、生字生成），保障隱私，無網絡環境下也能流暢運作。

🗄️ 資料儲存管理：SQLite3 & SQLAlchemy

輕量級本機資料庫，免架設伺服器。高效儲存與讀取單字資料、歷史對話與學習成效數據。

System Settings

系統設定與環境配置 (System Settings)

全方位自訂參數與連線監測機制

模型參數即時微調

直覺調整溫度參數 (Temperature)，對話時可調高創意度，轉 SQL 時可調低以求精準度。

一鍵測試連線

整合 SQLite 資料庫，配置成功後即時顯示連線狀態與版本提示，確保資料讀寫穩定。

對話歷史清空

提供一鍵「清除對話歷史」功能，隨時重置對話上下文與快取記憶，維護系統乾淨度。

Feature 01

核心功能一：💬 智能 AI 對話模組 (AI Chat)

具備動態角色與長上下文記憶的智能助手

動態 Persona 切換

可隨時切換為「資料庫專家 (Database Expert)」或其他專業角色，AI 自動調整對話風格與專業領域知識。

上下文記憶長對話

透過 LangChain 的 Memory 機制，AI 能記住前文對話內容，實現流暢、具備連續性的問答與代碼除錯。

本地隱私保障

所有的聊天對話均在本地端模型運行，企業或個人敏感資料絕對不會外流至任何雲端伺服器。

Feature 02-A

核心功能二(A)：🗄️ 智慧資料庫分析功能 (Smart Schema Analyzer)

技術亮點：自動解析結構與關聯網絡

資料結構自動解析與動態監測

  • 連線成功後，自動抓取資料庫類型與版本
  • 精準列出全庫資料表（如 chat_messages, english_practice）
  • 動態讀取並呈現各表目前列數 (Row Count) 及詳細欄位型態 (INTEGER, TEXT)

AI 智能用途辨識與關聯檢測

  • 由 AI 自動判讀並定義資料表屬性（業務資料表 / 設定資料表）
  • 外鍵關聯智慧檢測：自動判讀資料表之間是否存在外鍵關聯
  • 輔助使用者一目了然掌握全庫資料模型網絡
Feature 02-B

核心功能二(B)：🗄️ 自然語言轉 SQL 查詢 (Text-to-SQL)

無需死記語法，用口語中文直接指揮資料庫

自然語言智慧翻譯（Text-to-SQL）

使用者只需輸入口語化的中文指令（例如：「我需要查詢目前字典有多少類型且各類型有多少字的語法」），系統透過 LangChain 結合當前 Schema 結構，精準生成正確的 SQL 指令。

即時執行與數據視覺化

AI 生成 SQL 後可一鍵直接在本地 SQLite 執行，並將查詢結果以直觀的表格呈現，同時支援將結果匯出下載為 CSV 檔案進行後續分析。

Feature 03

功能亮點：📘 智能英文學習系統 (Smart Vocabulary)

結合 AI 智能化生成與科學化卡片複習

AI Auto-Vocabulary (一鍵生成生字集)

使用者可自訂主題（如：TOEFL 核心字彙）、難度與生成數量。AI 自動生成單字、翻譯及例句，並自動匯入本機字庫，免去手動輸入的麻煩。

學習成效追蹤

系統自動記錄總單字數量、測驗次數，並顯示今日複習狀態提醒，幫使用者建立科學化的每日學習習慣。

Core Operation

核心操作：🃏 單字卡片與字典查詢 (Flashcards & Dictionary)

靈活的多功能學習記憶工具

雙向卡片模式

支援切換「顯示英文」或「顯示中文」自我測驗，可快速切換上/下一張，並支援一鍵收藏單字至個人口袋清單。

分類管理與手動擴充

支援自訂新增分類標籤（如：TOEFL、未分類）。內建字典式查詢，允許手動編輯或新增英文、中文說明、例句與例句翻譯，並一鍵儲存（💾）至本機資料庫。

Analytics

情境測驗與成效趨勢 (TOEFL Quiz & Analytics)

數據化驗收學習成果

情境式模擬測驗

系統由字庫或 AI 自動出題，提供多選一的互動測驗（如單字在特定語境下的語意選擇），全面驗收學習成果。

數據化學習趨勢

提交答案後立即計算並更新「最近準確率」。詳細羅列每日的測驗日期、分類、題數與準確率，實現科學化的學習成效回饋。
